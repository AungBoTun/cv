# Personal Site — Replacement Package

This is a pure static site (HTML/CSS) ready for GitHub Pages.

## Publish
1) Create a new repo (or replace existing files).
2) Upload everything in this folder.
3) In GitHub: **Settings → Pages** → Deploy from branch (main).

## Customize
- Edit `index.html` (your landing page).
- Edit `/projects/*.html` for each project.
- Tweak styles in `css/style.css`.
- Put your images in `/images/` with the names referenced by `index.html`.

## Notes
- The file `.nojekyll` disables Jekyll processing (optional but recommended).
- If you use a custom domain, add a `CNAME` file with your domain.
