Developer Portal (Envoy + Istio + MCP)

Self-service creation of public/internal services with secure defaults and observability.

Benefits

  • Golden-path templates for speed
  • Security by default (mTLS, JWT, rate-limits)
  • Standard traces/dashboards for every service

Quick Steps

  1. Create a spec (service, tenant, repo)
  2. Generate Kubernetes + Gateway manifests
  3. Merge PR → routed via Envoy
