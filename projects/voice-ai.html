Voice & AI Data Pipeline

Ingest calls, transcribe, redact, summarize, and answer queries with optional geo context.

Description

A cost-effective pipeline using managed STT/LLM or local models; ingests audio, applies diarization and PII redaction, stores transcripts, and supports QA/search.

Tech & Design

  • FastAPI ingest (HTTP/WebSocket)
  • STT (managed API or Whisper), diarization/VAD
  • PII redaction (rules + DLP)
  • Postgres (+pgvector), optional PostGIS for geo

Architecture

Ingest → STT → Diarize/Redact → Summarize → Index (Postgres/pgvector)

Benefits

  • Searchable knowledge from calls
  • PII redaction and auditability
  • Geo-aware answers (PostGIS optional)

Quick Steps

  1. Deploy ingest API; set STT/LLM API keys
  2. Store audio in S3/GCS; transcripts in Postgres
  3. Use Grafana/Tempo to inspect traces
