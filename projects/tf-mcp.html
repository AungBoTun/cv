Terraform Generator via MCP (S3)

Generate standards-based Terraform from a YAML spec; plan and apply with guardrails.

Description

Dev provides a simple spec; MCP renders module-based Terraform, runs plan in CI with security checks, and applies when approved.

Tech & Design

  • Terraform modules + conftest/OPA checks
  • tfsec/checkov security scans in CI
  • OIDC to cloud for credentials
  • Terragrunt optional for multi-env

Architecture

Dev → MCP render → PR → CI checks → plan/apply

Benefits

  • Consistency via modules
  • Policy-as-code (OPA) gates
  • Fast provisioning with human approve/apply

Quick Steps

  1. Fill YAML spec (bucket, tags, tenant)
  2. Render stack and run plan
  3. Approve and apply
