FinOps + Security Program

Cut cost while increasing security and reliability via policies, autoscaling, and signed images.

Description

A focused initiative that adds cost visibility, rightsizing, and supply-chain security to every workload without hurting SLOs.

Tech & Design

  • OpenCost + Grafana dashboards
  • Gatekeeper policies (limits, probes, registries)
  • Kyverno verifyImages (Cosign, keyless)
  • HPA/VPA/KEDA for autoscaling

Architecture

OpenCost → Grafana; Gatekeeper/Kyverno → admission; Cosign in CI

Benefits

  • ≥25% cost reduction target
  • Gatekeeper/Kyverno guardrails
  • Signed images and centralized secrets

Quick Steps

  1. Install OpenCost and enforce labels
  2. Apply Gatekeeper/Kyverno policies
  3. Enable HPA/VPA and schedule scale-down
